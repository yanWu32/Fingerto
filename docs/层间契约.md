# 层间契约（Inter-layer Contracts）

> 唯一事实源：`tests/contract.py`。本文档是对该文件的**解释性说明**，任何层都必须
> `from tests.contract import *` 复用同一套 schema 与校验函数，禁止在层内另立 schema。
> 四层数据流：**感知 → 切分 → 识别 → 智能体 → 应用**，契约只约束相邻层之间的交接面。

---

## 0. 总览

| 交接面 | 生产者 | 消费者 | 契约形状 | 校验函数 |
|---|---|---|---|---|
| 骨骼张量 | 感知层 / 切分层 | 识别层 | `(T, 27, 3)` | `check_skeleton_shape` |
| gloss JSON | 识别层 | 智能体层 | dict（3 字段） | `validate_gloss_output` |
| agent JSON | 智能体层 | 应用层 | dict（5 字段） | `validate_agent_output` |

**红线（已锁定）**：
- 识别层**只输出 gloss 序列 + 置信度 + 时间戳**，**不做任何决策 / 命令生成**；决策权 100% 在智能体层。
- 骨骼 **27 点 = 主手 21 点 + 上身 6 点（"单主手 + 上身"）**，绝不是"双手各 21 点"。若将来识别层确需双手，须先把契约扩到 48 点布局并同步更新本文件与 `perception/skeleton.py`。

## 1. 骨骼张量契约 `(T, 27, 3)`

### 1.1 字段常量（`tests/contract.py`）

```python
NUM_POINTS            = 27   # 关节总数
NUM_HAND_POINTS      = 21   # 主手 21 点（MediaPipe Hands 标准 21 点）
NUM_POSE_POINTS      = 6    # 上身 6 点（Pose 子集）
HAND_OFFSET          = 0    # 主手索引起点
POSE_OFFSET          = 21   # 上身索引起点
POSE_LANDMARK_IDX    = [0, 11, 12, 13, 14, 15]   # 鼻, 左肩, 右肩, 左肘, 右肘, 左腕
SKELETON_RANK        = 3    # (x, y, z)
SKELETON_SHAPE       = (-1, 27, 3)               # (T, 27, 3)
```

### 1.2 点序布局（27 点）

| 索引区间 | 含义 | 说明 |
|---|---|---|
| `0 – 20` | **主手 21 点** | MediaPipe Hands 标准：0 手腕，1–4 拇指，5–8 食指，9–12 中指，13–16 无名指，17–20 小指 |
| `21 – 26` | **上身 6 点** | Pose 子集：21 鼻 / 22 左肩 / 23 右肩 / 24 左肘 / 25 右肘 / 26 左腕 |

> 图卷积邻接由 `perception/skeleton.py` 的 `HAND_EDGES`（主手 20 边）+ `POSE_EDGES`（上身 7 边）拼成，详见 `recognition/models/graph.py`。

### 1.3 取值约束

- 形状：`(T, 27, 3)`，其中 `T ≥ 1`（序列长度，可变）。
- 第三维固定 3，依次为 `(x, y, z)`。
- 数值必须是有限值（`float`），**不允许 NaN / Inf / None**。
- 单位：归一化后坐标（鼻为原点、肩宽为尺度、肩线水平），无绝对米制；原始坐标也可传递，下游按需归一化。

### 1.4 校验函数

```python
def check_skeleton_shape(seq: Any) -> bool
```

- **语义：返回 `bool`**（`True` 合法 / `False` 非法），**不抛异常**。
- 校验项：
  1. 转 `numpy` 后 `ndim == 3`；
  2. `shape[1] == 27`，`shape[2] == 3`；
  3. 全部元素有限（`np.all(np.isfinite(arr))` 为 `True`）。
- 退化：若运行环境无 `numpy`，退化为纯结构检查（list/tuple 且各帧 27 点、每点 3 维）。

### 1.5 合法 / 非法示例

```python
import numpy as np
from tests.contract import check_skeleton_shape

# 合法
good = np.random.randn(30, 27, 3)
assert check_skeleton_shape(good) is True

# 非法：点数不对（28）
assert check_skeleton_shape(np.random.randn(30, 28, 3)) is False

# 非法：维度不对（缺 z）
assert check_skeleton_shape(np.random.randn(30, 27, 2)) is False

# 非法：含 NaN
assert check_skeleton_shape(np.full((5, 27, 3), float('nan'))) is False
```

## 2. 识别层 → 智能体层 契约（gloss JSON）

### 2.1 Schema（`GLOSS_SCHEMA`）

| 字段 | 类型 | 含义 | 取值约束 |
|---|---|---|---|
| `gloss_sequence` | `list[str]` | 手语词序列（gloss） | 元素均为 `str` |
| `confidence` | `list[float]` | 各词置信度，与 `gloss_sequence` **等长** | 每个 `c ∈ [0, 1]` |
| `timestamps` | `list[[start, end]]` | 各词时间区间（秒），与 `gloss_sequence` **等长** | 每个 `[s, e]` 且 `s ≤ e` |

### 2.2 校验函数

```python
def validate_gloss_output(obj: Any) -> bool
```

- **语义：合法返回 `True`；失败抛 `ValueError`（带中文说明）**。
- 校验项（顺序）：
  1. `obj` 必须是 `dict`；
  2. 三个字段必须**全部存在**且类型正确（`list`）；
  3. 三列表长度必须一致（= `n`）；
  4. 每个 `confidence` 必须是数值且 `0.0 ≤ c ≤ 1.0`；
  5. 每个 `timestamps` 元素是长度为 2 的序列且 `start ≤ end`；
  6. 每个 `gloss_sequence` 元素是 `str`。

> 注意：识别层 `recognition/predict.py` 内部已对每段窗口产出单元素 gloss JSON（一个窗口 → 一个 gloss + 置信度 + 时间窗）；多窗口拼接由上层（或应用层装配）负责，但**每段都必须独立满足本契约**。

### 2.3 合法 / 非法示例

```python
from tests.contract import validate_gloss_output

# 合法
ok = {
    "gloss_sequence": ["你好", "我"],
    "confidence":     [0.92, 0.85],
    "timestamps":     [[0.0, 1.2], [1.3, 2.0]],
}
assert validate_gloss_output(ok) is True

# 非法（抛 ValueError）
bad_cases = [
    {"gloss_sequence": ["你好", "我"], "confidence": [0.9],           "timestamps": [[0.0,1.2],[1.3,2.0]]},  # 长度不一致
    {"gloss_sequence": ["你好", "我"], "confidence": [1.5, 0.2],      "timestamps": [[0.0,1.2],[1.3,2.0]]},  # 置信度越界
    {"gloss_sequence": ["你好", "我"], "confidence": [0.9, 0.8],      "timestamps": [[2.0,1.0],[1.3,2.0]]},  # start>end
    {"gloss_sequence": ["你好", 1],    "confidence": [0.9, 0.8],      "timestamps": [[0.0,1.2],[1.3,2.0]]},  # 非 str
    {"gloss_sequence": ["你好", "我"], "confidence": "0.9",           "timestamps": ...},                     # 非 list
]
for d in bad_cases:
    try:
        validate_gloss_output(d)
        print("BUG: 应抛 ValueError")
    except ValueError:
        pass  # 符合预期
```

## 3. 智能体层 → 应用层 契约（agent JSON）

### 3.1 Schema（`AGENT_SCHEMA`）

| 字段 | 类型 | 含义 | 取值约束 |
|---|---|---|---|
| `natural_language` | `str` | 回复的自然语言文本 | 任意字符串（可空，但应为 `str`） |
| `intent` | `str` | 意图标识 | 非空串；常见 `chat` / `query` / `command` / `clarify` |
| `task` | `str` | 可执行任务标识 | 非空串；无任务时固定为 `"none"`（**不是 dict，也不是空串**） |
| `clarification` | `bool` | 是否需要向用户澄清 | 必须是 `True` / `False`（**不能是 `null`/字符串**） |
| `low_confidence_words` | `list[str]` | 低置信度手语词（供澄清/高亮） | 必须是 `list` |

> **红线重申**：`task` 是字符串任务标识（如 `"close_window"`、`"weather_query"`、`"none"`），**绝不是动作 dict**；识别层不生成 `task`，`task` 完全由智能体层决策产出。

### 3.2 校验函数

```python
def validate_agent_output(obj: Any) -> bool
```

- **语义：合法返回 `True`；失败抛 `ValueError`**。
- 校验项：
  1. `obj` 必须是 `dict`；
  2. 五个字段必须全部存在；
  3. 按 `AGENT_SCHEMA` 类型严格校验（`list` / `bool` / `str`）；
  4. `intent` 与 `task` 不得为空字符串（无任务时 `task="none"`）。

### 3.3 合法 / 非法示例

```python
from tests.contract import validate_agent_output

# 合法
ok = {
    "natural_language":      "你想查询今天的天气吗？",
    "intent":                "query_weather",
    "task":                  "weather_query",
    "clarification":         False,
    "low_confidence_words":  [],
}
assert validate_agent_output(ok) is True

# 智能体的真实产出示例（消歧 + 控制意图）
ok2 = {
    "natural_language":      "我觉得冷，能关一下窗户吗？",
    "intent":                "command",
    "task":                  "close_window",
    "clarification":         False,
    "low_confidence_words":  ["冷"],
}

# 非法（抛 ValueError）
bad_cases = [
    {"natural_language":"x","intent":"q","task":"none","clarification":"no","low_confidence_words":[]},  # clarification 非 bool
    {"natural_language":"x","intent":"","task":"none","clarification":False,"low_confidence_words":[]},    # intent 空串
    {"natural_language":"x","intent":"q","task":"","clarification":False,"low_confidence_words":[]},       # task 空串
    {"natural_language":"x","intent":"q","task":"none","clarification":False,"low_confidence_words":"我"},# 非 list
]
```

## 4. 跨层公共入口

```python
def assert_contract(layer: str, obj: Any) -> bool
```

- `layer` 取值 `'gloss'` 或 `'agent'`，对 `obj` 调用对应校验函数。
- 合法返回 `True`；非法抛 `ValueError`；`layer` 取值非法抛 `ValueError`。
- 用途：各层在交付前做"契约闸门"自检（如 `recognition/predict.py` 与 `agent/pipeline.py` 在返回前都调用对应 `validate_*`）。

---

## 5. 与各层代码对接位置（核对用）

- 骨骼布局事实源：`perception/skeleton.py`（`HAND_OFFSET` / `POSE_OFFSET` / `POSE_LANDMARK_IDX`）。
- 切分输入/输出校验：`segmentation/segmenter.py` 的 `segment()` 调用 `check_skeleton_shape`。
- 识别层产出校验：`recognition/predict.py` 的 `Predictor.predict_window` 调用 `validate_gloss_output`。
- 智能体层产出校验：`agent/pipeline.py` 的 `AgentPipeline.run` 调用 `validate_agent_output`；`agent/systems.py` 四套系统均经 `validate_agent_output`。
- 契约单测：`tests/test_contract.py`（验证上述函数本身的合法/非法行为）。
