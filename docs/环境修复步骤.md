## 故障排查

### A. 卸载 opencv-python 后 `import cv2` 失败

说明 contrib 包也被破坏了。重装 contrib：

```powershell
pip install --force-reinstall opencv-contrib-python==5.0.0.93
```

### B. mediapipe 0.10.14 装不上（找不到 wheel）

Python 3.10 应该有对应 wheel。若报 `No matching distribution`，
先确认 Python 版本确实是 3.10：

```powershell
python -c "import platform; print(platform.python_version(), platform.architecture())"
```

必须是 **64 位**。若是 32 位 Python，mediapipe 不支持，需重建 64 位环境。

### C. 装完还是 `solutions: False`

可能装回了 1.x。强制指定并确认：

```powershell
pip uninstall mediapipe -y
pip install --no-cache-dir mediapipe==0.10.14
python -c "import mediapipe as mp; print(mp.__version__, hasattr(mp,'solutions'))"
```

### D. numpy 版本冲突

mediapipe 0.10.x 要求 numpy<2。你当前是 numpy 2.2.6，可能冲突。
若报 numpy 相关错误，降级 numpy：

```powershell
pip install "numpy<2"
```

> 注意：numpy<2 可能与 torch 2.5.1 有兼容提示，但通常不影响使用。
> 若 torch 出问题，再升回 numpy 2.x 并改用更高版本 mediapipe。

### F. 卸载 opencv-python 后 cv2 损坏（**已实测遇到**）

**症状：**
```python
>>> import cv2
>>> cv2.__version__
AttributeError: module 'cv2' has no attribute '__version__'
```

**原因：** `opencv-python` 与 `opencv-contrib-python` 共用同一个 `cv2` 目录。
卸载前者时，把后者装的 **`cv2.pyd` 原生扩展也一并删了**，
只剩一堆纯 Python 子模块，导致 `cv2` 变成空壳（`cv2.__file__` 为 `None`）。

**诊断命令：**
```powershell
python -c "import cv2; print(cv2.__file__)"        # 输出 None 即确认损坏
Get-ChildItem "E:\Program\anaconda\anaconda3\envs\fingerto\Lib\site-packages\cv2" -Filter "*.pyd"
# 无输出 = 没有 .pyd，确认损坏
```

**❌ 不要这样做：** 从其他 conda 环境（如 `pytorch`）复制 `cv2.pyd` 过来。
`.pyd` 是按 Python 版本编译的（cp38/cp310），跨版本会直接崩溃。
（`pytorch` 环境是 Python 3.8，fingerto 是 3.10，不兼容。）

**✅ 正确修复（必须联网）：**
```powershell
pip install --force-reinstall --no-cache-dir opencv-contrib-python==4.10.0.84
python -c "import cv2; print(cv2.__version__)"     # 应输出 4.10.0
```

> 建议装 **4.x 而非 5.0.0.93**：mediapipe 0.10.x 与 OpenCV 4.x 同期，兼容性更好。
