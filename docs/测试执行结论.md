## 二、环境性失败（非代码缺陷）：fingerto 未安装 pytest

**现象**：`tests/test_data.py` 原文件在模块顶层直接 `import pytest`（第 12 行），
而 fingerto 环境**未安装 pytest**，直接执行会在导入阶段崩溃：

```
ModuleNotFoundError: No module named 'pytest'
```

**判定**：这是**环境缺失依赖**导致，与被测代码正确性无关。
原因为该环境 pip 联网安装长期挂死（代理不通），无法补装 pytest。

**处置**：已把 `tests/test_data.py` 改造为**双模式**——

1. 装了 pytest 的环境：仍可 `pytest tests/test_data.py`（`test_*` 函数会被自动收集）；
2. 没装 pytest 的环境：可直接 `python tests/test_data.py`（新增 `main()` runner
   顺序执行 `CASE_LIST` 中全部 6 条用例并打印 PASS/FAIL 汇总）。

改造方式：`import pytest` 用 try/except 包成可选依赖（失败置 `None`），
文件末尾追加 `CASE_LIST` + `main()` + `if __name__ == "__main__"` 入口。
两种模式共用同一套用例，**不存在跳过或死测试**。
