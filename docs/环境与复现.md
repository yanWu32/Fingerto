# 环境与复现指南

> 面向毕设复现：从 0 搭建 `fingerto` 环境 → 生成合成数据 → 跑通测试与冒烟训练。
> 详细依赖与故障处理另见 `docs/环境配置指南.md`、`docs/环境修复步骤.md`。

---

## 1. 环境

- **包管理**：Anaconda（推荐）或 venv。
- **Python**：3.10.x（本机实测 3.10.22）。
- **核心依赖**：`torch`（建议 2.5.x + CUDA 12.1）、`numpy>=2`、`mediapipe==0.10.14`、`opencv-contrib-python==4.10.0`、`gradio`、`openai`、`pyyaml`、`pytest`。

> ⚠️ **MediaPipe 必须锁 0.10.x**：1.x 移除了 `mp.solutions`，与本项目不兼容。
> ⚠️ **只装 `opencv-contrib-python`**，不要同时装 `opencv-python`（共用 `cv2` 目录会互相覆盖）。

### 1.1 创建环境

```bash
conda create -n fingerto python=3.10 -y
conda activate fingerto

# 核心
pip install "torch==2.5.1+cu121" --index-url https://download.pytorch.org/whl/cu121
pip install "numpy>=2" mediapipe==0.10.14 opencv-contrib-python==4.10.0
pip install gradio openai pyyaml pytest
```

### 1.2 环境自检

```bash
python tools/check_env.py          # 依赖与 CUDA 检查
python tools/verify_perception.py  # MediaPipe 感知层验证（需摄像头/示例视频）
```

## 2. 生成合成数据集

中文手语数据集 ISW-1000 申请中，开发期使用**合成数据**（60 个中文孤立词类，固定种子可复现）。

```bash
conda activate fingerto
cd Fingerto
python data/make_testset.py
```

产物写入 `data/synthetic/`：

```
data/synthetic/
├── train.npz      # skeletons (N,T,27,3) / labels (N,) / classes (60,)
├── val.npz
├── test.npz
└── classes.txt    # 60 个中文 gloss
```

> 种子固定 `SEED=20261010`，同机复现结果一致。真实数据就绪后可用 `data/csl_loader.py`（CSL）或 `data/wlasl_loader.py`（WLASL 对照）转换，npz 格式与合成集一致。

## 3. 运行测试（契约地基 + 各层单测）

在 `Fingerto/` 根目录执行（保证 `tests` 为可导入包）：

```bash
conda activate fingerto
cd Fingerto
pytest tests/ -q
```

包含：

- `tests/test_contract.py` — **契约地基**：验证 `check_skeleton_shape` 返回 bool、`validate_gloss_output` / `validate_agent_output` 合法返回 `True`、非法抛 `ValueError`。
- `tests/test_perception_contract.py`、`tests/test_segmentation.py`、`tests/test_recognition.py`、`tests/test_agent.py`、`tests/test_agent_systems.py`、`tests/test_data.py`、`tests/test_wlasl.py` 等 — 各层与契约对接的冒烟测试。

---

## 4. 冒烟训练（无需真实数据）

```bash
# 合成数据上跑 ST-GCN 基线（默认 60 类，2 epoch 冒烟）
python recognition/train.py --mock --model stgcn --epochs 2

# 对比模型
python recognition/train.py --mock --model transformer_gcn --epochs 2
python recognition/train.py --mock --model cnn_lstm --epochs 2

# 保存权重后用真实/合成数据推理
python -c "from recognition import predict; print(predict(__import__('numpy').random.randn(30,27,3)))"
```

## 5. 快速验证智能体层（无需 LLM Key）

`agent/llm_client.py` 支持注入 `fake_completion` 回调，测试时不联网：

```bash
pytest tests/test_agent.py tests/test_agent_systems.py -q
```

四套消融系统（System A 规则 / B 无状态 / C 完整 / D 微调退化）均经 `validate_agent_output` 契约校验，可离线验证管线闭环。
