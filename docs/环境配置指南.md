# Fingerto 环境配置指南（手动执行版）

目标：新建 conda 环境 `fingerto`（Python 3.10），装上 torch(CUDA) + 项目依赖，
并配置 PyCharm 解释器与 LLM API Key。

> 每一步都可单独执行、可重复执行。遇错先看文末「故障排查」。

---

## 步骤 0：先让网络可用（否则后面全部失败）

你的系统代理是 `127.0.0.1:7897`，对应软件是 **Clash Verge Rev**
（位于 `C:\Users\22236\AppData\Roaming\io.github.clash-verge-rev.clash-verge-rev`）。
它当前**没在运行**，所以端口没监听，所有下载都会失败。

1. 启动 Clash Verge Rev（开始菜单或安装目录里的 exe）。
2. 在软件里确认已开启代理（系统代理/「打开面板」确认节点可用）。
3. 验证端口是否已监听：

```powershell
Get-NetTCPConnection -LocalPort 7897 -State Listen
```

4. 验证外网是否通：

```powershell
curl.exe -s -o NUL -w "pypi -> %{http_code}\n" --max-time 12 https://pypi.org/simple/
curl.exe -s -o NUL -w "tuna -> %{http_code}\n" --max-time 12 https://pypi.tuna.tsinghua.edu.cn/simple/
```

两条都返回 `200` 才继续。**返回 `000` 表示没通，不要往下走。**

## 步骤 3：安装 torch + torchvision（CUDA 12.1，匹配 RTX 4060）

```powershell
conda activate fingerto
pip install --upgrade pip
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
```

> 约 2.5 GB，耗时较长，请保持网络不中断。

验证 CUDA 是否可用：

```powershell
python -c "import torch; print(torch.__version__); print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'NO GPU')"
```

期望看到 `2.x.x+cu121`、`True`、`NVIDIA GeForce RTX 4060 Laptop GPU`。

## 步骤 6：PyCharm 配置项目解释器

1. 打开 PyCharm → `File` → `Settings` → `Project: Fingerto` → `Python Interpreter`
2. 右上角齿轮 → `Add Interpreter` → `Add Local Interpreter`
3. 选 **Conda Environment** → `Use existing environment`
   - 或直接选 **System Interpreter**，路径填：
     `E:\Program\anaconda\anaconda3\envs\fingerto\python.exe`
4. Apply / OK

验证：PyCharm 底部 Terminal 里执行 `python --version` 应显示 3.10.x。

## 步骤 7：配置 LLM API Key（智能体层用）

在 `Fingerto/` 根目录新建 `.env` 文件（**不要提交到 Git**，`.gitignore` 已排除）：

```env
# 二选一填一个即可（DeepSeek 主用 / 通义千问备用）
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx
# DASHSCOPE_API_KEY=sk-xxxxxxxxxxxxxxxx

# 可选：指定模型名
LLM_PROVIDER=deepseek
LLM_MODEL=deepseek-chat
```

- DeepSeek 申请：https://platform.deepseek.com/
- 通义千问（百炼）申请：https://dashscope.aliyun.com/

> 两者都是 OpenAI 兼容端点，`agent/llm_client.py` 会统一封装，换只需改 base_url + key。

## 故障排查

### A. 网络始终不通（端口 7897 无监听）
- 确认 Clash Verge Rev 已启动且节点可用
- 若换了端口，同步改系统代理：`设置 → 网络和 Internet → 代理`
- 或临时关闭系统代理（`ProxyEnable` 设为 0）后直连试试

### B. 离线手动安装（网络实在不通时）
在有网的机器上从清华源下载 wheel，拷回来装：

```powershell
# 例：mediapipe
pip download mediapipe -d D:\wheels --no-deps
pip install D:\wheels\mediapipe-xxx.whl
```

### C. mediapipe 在 Python 3.10 装不上
锁定兼容版本：

```powershell
pip install mediapipe==0.10.14
```

### D. torch 装成了 CPU 版
确认输出里带 `+cu121`。若是纯版本号（无 `+cu121`），重装：

```powershell
pip uninstall torch torchvision -y
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
```

### E. gradio 启动报端口占用
换端口：在 `app/gradio_app.py` 的 `launch()` 里加 `server_port=7861`。
