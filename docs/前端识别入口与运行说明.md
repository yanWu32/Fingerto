# 前端：视频识别入口与运行说明（新增）

本次在「前端中添加后端功能的基本要求的入口」：一个**仅接受视频**的上传入口、一个**开始识别**按钮，以及识别过程中**动态演示全链路**的页面。

## 新增页面 `/recognize`（视频识别）

- 入口：顶部导航「视频识别」、首页两个 CTA 之一。
- 功能：
  1. **视频上传（仅视频）**：`accept="video/*,.mp4,.avi,.mov,.webm"`，前端校验类型 + 大小（≤50MB，与后端 `MAX_UPLOAD_BYTES` 对齐），支持点击 / 拖拽，本地预览。
  2. **开始识别**：上传后点击「▶ 开始识别」。
  3. **动态演示过程**：识别中按阶段实时驱动时间轴（`PipelineFlow`）+ 阶段流水（`StageLog`）+ 骨架播放（`SkeletonCanvas`）+ gloss 序列与置信度（`GlossBoard`）+ 智能体三步提示管线（`AgentSteps`）+ 应用执行，最终给出「自然语言文本 / 任务 / 是否需要澄清」。
  4. **取消**：`■ 取消` 通过 `AbortController` 中断 fetch 并调用 `POST /api/pipeline/{jobId}/cancel`。

## 真实后端 / mock 自动切换（规范 1.3 数据无关先行）

- 页面启动识别前先 `GET /api/health` 探测（结果按 30s 缓存）。
  - 后端 `ready=true` → 走真实 **SSE 流式**（`POST /api/pipeline/stream`，逐事件驱动 UI）。
  - 探测失败 / `ready=false`（torch/mediapipe/cv2 未就绪）→ 自动降级到内置 **mock 演示**，UI 顶部「当前模式」徽标明示。
- 这是**运行时**切换：编译期 `VITE_USE_MOCK` 仍保留（用于纯演示构建）。

## 关于 `/api` 前缀（重要约定）

后端 `app/server.py` 注册的路由**本身不带** `/api` 前缀（`/recognition`、`/pipeline/stream`、`/health`、`/skeleton/{jobId}`…），而前端统一以 `/api` 调用。前缀剥离放在**代理层**（不属于后端代码）：

- 开发：`frontend/vite.config.ts` 的 `/api` 代理加了 `rewrite: path => path.replace(/^\/api/, '')`。
- 生产/一键启动：`serve.py` 的代理对 GET/POST 同时转发，并剥离 `/api` 前缀、支持**分块流式转发**（SSE 不被缓冲）。
- 生产 Nginx 同理加 `rewrite ^/api/(.*) /$1 break;`。

> 这样前端永远只认 `/api`，后端无需重复前缀，三者调用约定一致。

## SSE（流式）实现要点

- SSE 不走 axios（axios 不支持流式），集中在 `frontend/src/api/stream.ts`，用原生 `fetch` + `ReadableStream` 读取，逐行解析 `data: {envelope}`（envelope 内 `data` 为事件体）。
- 事件类型（`SseEvent`）：`stage` / `perception_done`(含可选内联骨架 `(T,27,3)`) / `segmentation_done` / `recognition_window` / `recognition_done` / `agent_step` / `agent_done` / `application` / `done` / `error`。
- 若 `perception_done` 未内联骨架，前端按 `jobId` 调 `GET /api/skeleton/{jobId}` 二次拉取（`(T,27,3)` 或 `null`）。

## 复用组件（DRY，安全关键）

`v-html` 仅出现在 `AgentSteps.vue`，且全部经过 `utils/sanitize.ts#highlightTokens`（先转义再包 `<mark>`），未分散到各页面。新增 `StageLog` / `GlossBoard` / `AgentSteps` 三个共享组件，`DemoView`（脚本演示）与 `RecognizeView`（真实入口）共用。

## 运行（真实后端）

```bash
# 仓库根目录，拉起前端 SPA + 真实 FastAPI 后端
python serve.py --backend-fastapi
# 打开 http://127.0.0.1:5173/recognize  ，上传手语视频即可
```

仅前端演示（mock，无需后端）：`python serve.py` 或 `cd frontend && npm run dev`。
