| 模块 | 文件 | 状态 |
|---|---|---|
| 运动能量粗切分 + 滑窗 | `segmentation/segmenter.py` | ✅ `SkeletonSegmenter.segment()` + `sliding_windows()` |

**核对要点**：
- 输入 `(T,27,3)`，经 `check_skeleton_shape` 校验。
- 运动能量取参考关节（默认 `left_wrist`→索引 0 主手腕、`right_wrist`→索引 26 上身左腕；注释明确"27 点仅含单手+上身"）速度范数。

- 配置可空（`configs/segmentation.yaml` 缺失时回退内建 `DEFAULTS`）。

**待办**：滑窗投票/Viterbi 时序平滑（代码留 `window.smoothing="vote"`/`vote_threshold`，细识别层对接待补）。

**核对要点**：
- 识别层输出**仅** `gloss_sequence + confidence + timestamps`，**不决策**（见 `predict.py` 顶部 docstring 与契约）。
- 模型输入 `(B,T,27,3)`；图邻接注释明确"单主手 + 上身，非双手"。
- **已修两处真实前向 bug**（d8288b8 回归修复）：ST-GCN 时间维不降采样、Transformer-GCN BN 轴错位、CNN-LSTM input_size 前向探测。
- **已修骨架图连通性 bug**（b11a843）：原 `POSE_EDGES` 未 +21 偏移（与手部碰撞）且缺 HAND→POSE 跨边，致上身 21-26 点被误判 center；现补 `POSE_EDGES_GLOBAL` + `HAND_POSE_BRIDGE=[(0,26)]` + `assert_graph_connected`。

**真实数据进度**：
- 合成 60 类集 ST-GCN val/test = **0.994 / 0.997**（随机基线 1.7%）✅
- WLASL100 真实英文 ASL（665 视频，100 类）已抽 27 点骨架并三模型训练（32747ef）：
  ST-GCN test 4.3%(top5 11.6%)、CNN-LSTM 10.1%(23.2%)、Transformer-GCN 未收敛。
  归因样本稀疏（~5.4/类），论证 ISW-1000 必要性；详见 `experiments/results/wlasl100_real_training.md`。

**待办**：中文数据集（ISW-1000 / CSL 申请中）到位后复跑真实指标；滑窗多段拼接成句；Transformer-GCN 真实数据调参。
