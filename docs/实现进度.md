## 2. 手势切分（segmentation）— ✅ 已实现

| 模块 | 文件 | 状态 |
|---|---|---|
| 运动能量粗切分 + 滑窗 | `segmentation/segmenter.py` | ✅ `SkeletonSegmenter.segment()` + `sliding_windows()` |

**核对要点**：
- 输入 `(T,27,3)`，经 `check_skeleton_shape` 校验。
- 运动能量取参考关节（默认 `left_wrist`→索引 0 主手腕、`right_wrist`→索引 26 上身左腕；注释明确"27 点仅含单手+上身"）速度范数。
- 自适应阈值（MAD/STD）→ 活跃帧 → 合并（短静默合并、短片段丢弃、超长截断）→ 产出 `Segment` 列表；每段滑窗产出 `(w,27,3)` 细识别窗口。
- 配置可空（`configs/segmentation.yaml` 缺失时回退内建 `DEFAULTS`）。

**待办**：滑窗投票/Viterbi 时序平滑（代码留 `window.smoothing="vote"`/`vote_threshold`，细识别层对接待补）。

| 模块 | 文件 | 状态 |
|---|---|---|
| 三步提示管线 | `agent/pipeline.py` | ✅ Step1 确认消歧 → Step2 翻译 → Step3 决策 |
| 对话状态 | `agent/dialogue_state.py` | ✅ 历史/环境/偏好/待确认意图 + 指代消解 + 纠正检测 |
| 四套消融系统 | `agent/systems.py` | ✅ System A/B/C/D 工厂 `build_system` |
| 缓存 | `agent/cache.py` | ✅ `TranslationCache`（TTL/落盘） |
| LLM 客户端 | `agent/llm_client.py` | ✅ OpenAI 兼容（deepseek/qwen/local），支持 `fake_completion` 注入 |

**核对要点**：
- 三层 prompt 模板均在 `pipeline.py`：SYSTEM_TRANSLATE / SYSTEM_CONFIRM / SYSTEM_DECISION。
- `run()` 整合三步产出 agent JSON，并经 `validate_agent_output` 闸门；低置信词路由（默认 `clarify_threshold=0.4`）。
- System A 规则基线（无 LLM）/ B 无状态单轮 / C 完整管线（主系统）/ D 微调小模型（无权重时退化为 C）。
- 决策完全在智能体层（`task` 为字符串标识），识别层不生成命令。

**待办**：System D 真实微调权重接入（`_local_generate` 当前抛 NotImplementedError）；多轮指代/纠正的端到端场景测试；意图类型与 `ALLOWED_ACTIONS` 与开题报告指标对齐确认。
